# Wave Shooter 3D

3D-арена шутер. Игрок в центре, со всех сторон лезут враги, отстреливаешься, выживаешь.

**Стек:** Three.js (3D-библиотека) + ванильный JS + HTML5. Без сборщиков, без сервера.

## Запуск

Двойной клик на `index.html` — открывается в браузере, нужен интернет (Three.js подгружается с CDN).

Если хочешь работать оффлайн — скачай `three.min.js` с https://unpkg.com/three@0.149.0/build/three.min.js, положи рядом и поправь путь в `index.html`.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD    | Движение |
| Мышь    | Прицел |
| ЛКМ     | Стрельба |
| Esc / P | Пауза |
| M       | Mute |

**На телефоне/планшете:** твин-стик. Левый палец на левой половине экрана — джойстик движения. Правый палец на правой половине — прицел и автострельба.

## Что есть сейчас

- 3D-арена с тенями, туманом, движущимся солнцем
- Игрок (жёлтый цилиндр со стволом), WASD движение, прицел через мышь
- Стрельба, светящиеся пули, тряска камеры при попадании
- Враги (красные кубики) спавнятся вокруг и идут к игроку, контактный урон
- HP, киллы, счёт, таймер
- **Опыт и уровни:** убитые враги дронят синие сферы опыта, ты их собираешь (есть магнит)
- **Апгрейды на левел-ап:** игра ставится на паузу, выбираешь 1 из 3 случайных:
  - Урон, скорострельность, скорость, HP, мультивыстрел, пробивание, магнит, лечение, скорость пуль

## Что есть теперь (этап 3)

**Типы врагов** (открываются с таймером):
- 🟥 **Грант** — базовый красный, средне всё (с самого начала)
- 🔵 **Скаут** — голубой, маленький, быстрый, бьёт меньше (с 25 сек)
- 🟫 **Танк** — большой тёмно-красный, медленный, толстый, бьёт сильно (с 50 сек)
- 🟪 **Стрелок** — фиолетовый, останавливается на дистанции и стреляет розовыми сферами (с 80 сек)

**Боссы:**
- Каждые 60 сек появляется босс с предупреждением "BOSS!"
- Огромный фиолетовый куб со светящимися глазами и полоской HP над головой
- HP и урон растут с каждой минутой (1-й босс ~1400 HP, 2-й ~2000, и т.д.)
- При смерти вываливают **20+ кристаллов опыта** — мгновенный левел-ап-фейерверк

## Что есть теперь (этап 4: звук + полировка)

- **Звук:** все эффекты синтезированы через Web Audio API (никаких файлов)
  - Стрельба, попадание, смерть врага, смерть босса, спавн босса, левел-ап, пикап, урон
- **🔊 кнопка** в правом нижнем углу или клавиша **M** — мьют. Сохраняется в localStorage.
- **Esc или P** — пауза. На паузе фоновый рендер продолжается, но физика стоит.
- **Лучший счёт** сохраняется в localStorage, показывается на старте и в конце забега.
- На рекорде в конце игры выводится «★ NEW BEST».
